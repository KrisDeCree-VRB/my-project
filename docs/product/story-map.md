# User Story Map: Weekend Away

## Goal

Give a small group of friends one shared place to plan a weekend away — the trip itself, what they'll do, what they'll bring, and who does what — so the plan stops living scattered across a group chat where nobody knows who booked the house or who's bringing the barbecue.

## Primary User

One of the friends in the group, usually whoever kicks the trip off. They want to get a weekend organised without chasing people. Everyone invited is a full participant: they can see the whole plan and contribute to it, not just read it.

## Story Map

### Set up the trip and get everyone in

| #   | Story                                                                                                        |
| --- | ------------------------------------------------------------------------------------------------------------ |
| 001 | As a trip starter, I can create a trip with a name, location and start/end dates so the group has one place to gather around |
| 002 | As a trip starter, I can invite friends with a shareable link so they can join without me setting up accounts for them |
| 003 | As an invited friend, I can join a trip and set my display name so everyone knows who I am in the plan        |
| 004 | As a participant, I can see who's coming and mark myself as in, out or unsure so the group knows the headcount |
| 005 | As a participant, I can see all the trips I'm part of so I can jump back into the right one                   |

### Plan what we'll do

| #   | Story                                                                                                        |
| --- | ------------------------------------------------------------------------------------------------------------ |
| 006 | As a participant, I can add an activity idea with a short description so the group can consider it            |
| 007 | As a participant, I can give an activity a day and a time so it lands in the weekend schedule                 |
| 008 | As a participant, I can see the weekend as a day-by-day schedule so I know what's happening when              |
| 009 | As a participant, I can vote on activity ideas so the group can tell which ones people actually want          |
| 010 | As a participant, I can mark an activity as booked or confirmed so nobody wonders whether it's actually sorted |

### Plan what we'll bring

| #   | Story                                                                                                        |
| --- | ------------------------------------------------------------------------------------------------------------ |
| 011 | As a participant, I can add an item to the bring list so it doesn't get forgotten                             |
| 012 | As a participant, I can claim an item so everyone can see who's bringing the barbecue                         |
| 013 | As a participant, I can tick an item as packed so the group can see what's actually handled                   |
| 014 | As a participant, I can see which items nobody has claimed yet so the gaps are obvious at a glance            |
| 015 | As a participant, I can group the bring list by category (food, gear, drinks) so it's usable while shopping   |

### Divide up who does what

| #   | Story                                                                                                        |
| --- | ------------------------------------------------------------------------------------------------------------ |
| 016 | As a participant, I can add a task with an optional due date so responsibilities are written down             |
| 017 | As a participant, I can assign a task to someone (including myself) so it has a clear owner                   |
| 018 | As a participant, I can mark a task done so the group sees progress instead of asking                         |
| 019 | As a participant, I can see just my own tasks and claimed items so I know what I'm personally on the hook for |

### See the whole plan at a glance

| #   | Story                                                                                                        |
| --- | ------------------------------------------------------------------------------------------------------------ |
| 020 | As a participant, I can open a trip overview showing the countdown, who's coming, the schedule and what's still open |
| 021 | As a participant, I can see a recent-activity feed of what changed so I can catch up without re-reading everything |
| 022 | As a participant, I can leave a comment on an activity, item or task so discussion stays next to the thing it's about |
| 023 | As a participant, I can view the trip comfortably on my phone so I can use it while out and about             |
